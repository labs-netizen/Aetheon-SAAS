## 3. Gaps Remediated in this Pass

1. **Role Switcher Production Hardening**: Gated client-side demo role switcher behind `NEXT_PUBLIC_DEMO_MODE !== 'false'`.
2. **Internal Admin Boundary**: Hardened `/admin` route against non-Aetheon roles (customer `ORGANISATION_ADMIN`, etc. are strictly blocked).
3. **Security Test Suite Expansion**: Expanded `tests/integration/security_isolation.test.ts` to 10 comprehensive tests covering all security, entitlement, regulatory, ingestion, and webhook replay boundaries.
4. **BESS Terminology & Guardrails**: Replaced all dispatch-oriented phrasing with advisory language ("recommended charge/discharge opportunity windows") and verified safety lockouts suppress signals.
5. **DSM Missing Data Behavior**: Verified that missing meter or schedule telemetry triggers hard suppression rather than synthetic penalty estimates.
6. **Synthetic Data Labeling**: Audited all seeded mock data and verified that all synthetic tariffs, DSM rules, and market prices carry clear `DEMO / UNVERIFIED` banners.
7. **End-to-End Test Suite**: Configured and executed Playwright headless test suite covering all critical customer and administrative flows.
